# S1 — Public source CT spatial reference

The [authors' dataset](https://inrepo02.dkfz.de/record/299862) includes original baseline images and synthetic follow-ups with corresponding instance IDs, under CC BY-NC-SA 4.0. The bounded reference uses two complete pairs each from KiTS23, LIDC-IDRI and NSCLC Radiogenomics. The named origin comes from the release's naming table. For each origin the selection ranks eligible pairs by SHA-256 with a fixed seed and takes the first two. Eligibility requires the four image/mask members and at most 144 MiB across the pair. The CPU job retrieves only ZIP byte ranges, verifies each member through ZIP CRC and independent R2 SHA-256, and keeps the original case mapping private.

The source CT uses the released intensity values and lesion instance labels. Its anatomy proxy is intensity above −500 in the released CT values. Positive labels define the author-provided lesion instances. Native volume uses the determinant of the native affine. The geometric reference uses the actual fold-0 tracking checkpoint plans with original spacing 3×0.841796875×0.841796875 mm in reader axis order. The [paper supplement](https://openaccess.thecvf.com/content/CVPR2025/supplemental/Rokuss_LesionLocator_Zero-Shot_Universal_CVPR_2025_supplemental.pdf) describes a higher-resolution 1×0.8×0.8 mm tracking ROI. That condition is evaluated separately in S2 while preserving the released checkpoint tensor sizes.

## Verified reference distribution

The six pairs yield 12 CT examinations and 11 baseline lesion instances. All 11 remained present in the work space and in the 175³ historical registration input. The 5th/50th/95th percentiles of lesion voxels were 96/1,390/70,619 natively, 121/1,329/116,676 after official work-space preprocessing, and 32/356/25,245 in the registration grid. Median registration bounding extent was 11×9×8 voxels. Median registration field of view was approximately 292.5×389.8×389.8 mm, with median effective-anatomy proxy occupancy of 42.5%.

The GT-centered local ROI is a geometric oracle. It uses the original patch shape and measures a separate U-Net input distribution. Its median native-to-work lesion extent was 6×27×21 work voxels, median lesion occupancy 0.0211%, median pad occupancy 3.125%, and median anatomy occupancy 69.0%. Median actual ROI field of view was 279×215.5×215.5 mm. Regional source intensities, field-of-view quantiles, padding axes, lesion boundary distances, patient-level maps and example panels are preserved in the verified results. This small reference represents the sampled released CT assets. Exact checkpoint training membership, larger out-of-domain anatomy and observed learned-warp ROI distributions remain outside this reference.
