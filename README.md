# Brain Tumour CNN-ViT Segmentation

This repository contains a reproducible research pipeline and a Gradio deployment demo for brain tumour segmentation and volumetry on the MSD Task01 BrainTumour dataset.

The primary model is a CNN-ViT transfer-learning segmenter based on the pretrained hybrid model [`timm/vit_base_r50_s16_224.orig_in21k`](https://huggingface.co/timm/vit_base_r50_s16_224.orig_in21k). The final binary model is evaluated on a frozen held-out test split of 73 patients.

Live deployment:

```text
https://huggingface.co/spaces/TLOMMP/brain-tumour-segmentation
```

## Highlights

- Patient-level tumour-volume-stratified 70/15/15 split:
  - Train: 339 patients
  - Validation: 72 patients
  - Test: 73 patients
- Native 240 x 240 MRI slice geometry is preserved.
- Input shape: `(240, 240, 155, 4)`.
- Binary whole-tumour segmentation is the primary endpoint.
- 4-label segmentation is included as a separate extension branch.
- Deployment app supports binary and 4-label inference with interactive 3D/2D visualization.

This repository intentionally does not include the raw MSD/BraTS NIfTI data. To reproduce training or inference locally, prepare the MSD Task01 BrainTumour files under:

```text
└── labelsTr/
```

## Model Summary

The model adapts a pretrained hybrid R50-ViT model for MRI segmentation:

- 4-channel MRI input instead of RGB.
- Native 240 x 240 slice input.
- Hybrid ResNet-ViT token grid: 15 x 15 image tokens.
- Positional embedding interpolation from 14 x 14 to 15 x 15.
- Decoder upsamples 15 -> 30 -> 60 -> 120 -> 240.
- Binary model uses sigmoid + threshold for whole-tumour segmentation.
- 4-label branch uses softmax + argmax for tumour subclasses.

The final binary training setting fine-tuned:

- input stem,
- positional embedding,
- ResNet stage 2,
- last 4 ViT blocks,
- encoder norm,
- segmentation decoder.

## Reproduction

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Audit Data

```bash
python scripts/01_data_audit.py \
  --data-root data/processed/Task01_BrainTumour \
  --output-dir outputs/data_audit
```

### 3. Use the Frozen Split

The frozen split is included at:

```text
outputs/splits/frozen_patient_split_seed42.csv
```

It was generated by stratifying patients by whole-tumour volume quartiles.

### 4. Train Binary Segmentation

```bash
python scripts/04_train_route_b.py \
  --split-manifest outputs/splits/frozen_patient_split_seed42.csv \
  --data-root data/processed/Task01_BrainTumour \
  --weights models/pretrained/timm/vit_base_r50_s16_224.orig_in21k/model.safetensors \
  --output-dir run_outputs/route_b_binary \
  --epochs 15 \
  --batch-size 16 \
  --trainable-vit-blocks 4 \
  --trainable-resnet-stages 2 \
  --train-stem \
  --train-pos-embed \
  --require-full-val
```

### 5. Run Binary Test Inference

```bash
python scripts/05_infer_route_b.py \
  --checkpoint checkpoints/binary_route_b_best_checkpoint.pt \
  --split-manifest outputs/splits/frozen_patient_split_seed42.csv \
  --data-root data/processed/Task01_BrainTumour \
  --mode test \
  --output-dir run_outputs/route_b_test \
  --save-case-metrics
```

### 6. Run 4-label Inference

```bash
python scripts/07_infer_route_b_4label.py \
  --checkpoint checkpoints/route_b_4label_best_checkpoint.pt \
  --split-manifest outputs/splits/frozen_patient_split_seed42.csv \
  --data-root data/processed/Task01_BrainTumour \
  --mode test \
  --output-dir run_outputs/route_b_4label_test
```

## Deployment

The deployed web app is available at:

```text
https://huggingface.co/spaces/TLOMMP/brain-tumour-segmentation
```

The Gradio app lives in:

```text
deployment/binary_seg_mvp/
```

It provides:

- `.nii` / `.nii.gz` upload,
- strict shape validation,
- binary or 4-label model selection,
- optional label upload,
- tumour volume and tumour/brain percentage,
- 3D Plotly brain/tumour rendering,
- three local 2D slice viewers,
- job-id based result reload.

Run locally:

```bash
cd deployment/binary_seg_mvp
python app.py
```
